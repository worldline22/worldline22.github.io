A 60-second starting point

A chip needs a plan, a program, and a reality check.

The papers connect these pieces at different levels.

RTL
A hardware description of registers and the logic that updates them.
Hierarchy / module
A design built from smaller blocks with defined connections.
Mapping
Assigning a workload’s operations and data to hardware resources.
PPA
Power, performance, and area: physical costs and speed of an implementation.
SoC / CGRA
A system-on-chip / an array of configurable arithmetic units.
IR / synthesis
A structured compiler representation / turning a hardware description into a circuit.
