A 60-second starting point

Moving numbers can cost more than calculating.

These papers attack different parts of that problem.

Tensor
An array of numbers. A matrix is a 2D tensor.
Operator / kernel
The mathematical task / the program that executes it.
Fusion
Connect operations so intermediate results can be reused.
Tile
A smaller piece of a tensor processed at a time.
Layout
The arrangement of tensor elements in memory.
Cost model
An estimate of execution time, energy, or resource use.
